# PathTrial for Cursor

Cursor plugin package for the local PathTrial MCP server. It starts `pathtrial mcp` and does not embed an allowlist.

The public Cursor Marketplace does not list this package until it is submitted and reviewed. Load it locally, import the repository as a team marketplace, or copy `mcp.json` into Cursor's MCP config.

`pathtrial` must already be on the `PATH` Cursor uses. Installing this package does not download the CLI.

## Layout

```text
plugins/cursor/pathtrial/
├── .cursor-plugin/plugin.json
├── mcp.json
├── rules/pathtrial-evidence.mdc
├── skills/
└── README.md
```

`mcp.json` is only:

```json
{
  "mcpServers": {
    "pathtrial": {
      "type": "stdio",
      "command": "pathtrial",
      "args": ["mcp"]
    }
  }
}
```

## Allow targets

Do not edit this file to authorize hosts. Create the user allow file instead.

- Linux and macOS: `~/.config/pathtrial/allow-targets`
- Windows: `%APPDATA%\pathtrial\allow-targets`

One explicit host or `host:port` per line. No wildcards or CIDR. A missing file denies every probe. Cursor Desktop may not inherit `PATHTRIAL_MCP_ALLOW_TARGETS` from a terminal. Restart Cursor after changing the file.
