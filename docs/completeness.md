# PathTrial 功能完成度矩阵

本文件在开发前确定权重与验收项，用于计算最终完成度。**不得为了凑分临时调整权重。**
状态定义：

- `VERIFIED`：实现完成，且有本地可重复测试或真实协议交互验证。
- `PARTIAL`：部分验收项通过，按通过项比例计分。
- `NOT IMPLEMENTED`：零分。
- `UNVERIFIED`：代码存在但缺少必要验证，不计为完成。

## 权重

| 维度 | 权重 |
| --- | ---: |
| 14 个模块的功能验收 | 70% |
| 跨平台验证（macOS arm64 / macOS x86_64 / Linux x86_64 / Windows x86_64） | 15% |
| 安全、隐私、探测预算与回归测试 | 10% |
| 文档、发布构建与安装体验 | 5% |

每个模块的功能分 = 70% / 14 = 5 个百分点。模块内各验收项等权。

## M01 系统环境与网卡

1. 操作系统、架构、内核
2. 网卡列表、地址、状态
3. 默认路由与目标路由
4. 隧道类接口提示与代理环境变量名（只记名字）
5. macOS / Linux 平台适配

## M02 DNS

1. 系统解析器 A/AAAA
2. 用户显式指定解析器
3. 多解析器结果对照
4. 解析耗时与 rcode 分类
5. Fake-IP 与 Split DNS 私有地址区分

## M03 IPv4 / IPv6

1. 本机地址族支持检测
2. 按地址族分别探测
3. 同窗口双栈对照
4. 缺一族时 SKIP 并写明原因

## M04 路由与 traceroute

1. 默认路由与目标路由
2. 逐跳路由检测
3. 每跳地址、RTT、超时、是否到达
4. 缺少工具或权限时 SKIP 并写明原因

## M05 ICMP

1. Ping 探测（不要求 root）
2. 发送/接收数量、丢包率、RTT
3. 中位数与抖动
4. 目标限制 ICMP 时的证据边界

## M06 TCP

1. 非阻塞 connect + 硬超时
2. 错误分类（超时/拒绝/不可达/重置）
3. 拒绝与超时的语义区分
4. 平均值/中位数/最大值，仅统计成功样本
5. 总预算与轮次上限

## M07 TLS

1. 握手与耗时
2. 协议版本与密码套件
3. 证书有效期、SAN、链长度
4. 传输失败与证书失败分开记录
5. SNI 覆盖（字面 IP 场景）

## M08 HTTP/HTTPS

1. 真实请求（GET，HTTP/1.1）
2. 分段计时：DNS / TCP / TLS / 首字节 / 总耗时
3. 状态码与预期状态码校验
4. 重定向记录但不跟随跨目标跳转
5. 4xx/5xx 不归类为底层网络不可达
6. 复用接口绑定与地址族选择

## M09 UDP

1. 应用层 Echo 客户端（序号 + 载荷匹配）
2. ICMP 不可达 / 超时 / 无效响应区分
3. 成功率、RTT、丢包统计
4. 可选 Echo 服务端（默认只监听回环）

## M10 QUIC / HTTP3

1. 真实 QUIC 握手
2. ALPN 与证书验证
3. 握手错误与应用错误分离
4. 不支持 QUIC 的目标判为 SKIP

## M11 代理检测

1. SOCKS5 无认证 CONNECT
2. HTTP CONNECT 隧道
3. 错误分类（代理不可达 / 拒绝 / 需要认证 / 隧道成功但目标 TLS 失败）
4. 直连与代理的同目标、同窗口对照
5. 不记录凭据

## M12 双端诊断

1. 客户端采集
2. 服务端采集
3. 离线关联（不依赖 SSH）
4. 时钟误差与缺失抓包的限制说明

## M13 对照分析

1. 两份报告的目标/端口/协议一致性检查
2. DNS、TCP、TLS、HTTP 差异
3. 采样条件不一致时拒绝严格比较

## M14 综合报告

1. JSON Schema 校验
2. 三种输出格式一致的状态逻辑
3. 每条 Finding 引用真实 probe ID
4. 脱敏模式
5. 证据边界与未证实项
