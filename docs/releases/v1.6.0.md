# PathTrial v1.6.0

PathTrial is a local-evidence-first network diagnostics MCP with a standalone Rust CLI.

## Highlights

- Canonical evidence findings now carry `claim`, `evidence`, `probe_id`,
  `confidence`, `limits` and `not_established`.
- `pathtrial fingerprint` records IPv4/IPv6 exit identity, DNS chain, TLS
  certificate SHA-256, local proxy hops and address-family fork.
- `pathtrial fingerprint-diff` reports deterministic changes between two
  captures.
- Three new diagnosis scenarios: `vps-unreachable`, `proxy-split` and
  `http3-fallback`.
- MCP grows from ten to twelve tools with `pathtrial_fingerprint` and
  `pathtrial_fingerprint_diff`. Probes remain default-deny.

## Schema versions

- Scan report: `1.6.0`
- Guided diagnosis: `1.1.0`
- Canonical evidence finding: `1.0.0`
- Path fingerprint: `1.0.0`
- Fingerprint comparison: `1.0.0`

## Install

Choose macOS Apple Silicon, macOS Intel, Linux x86_64 or Windows x86_64 from the
release assets. Verify the adjacent SHA-256 file before installing.

- macOS and Linux: use `install.sh`.
- Windows: use `install.ps1`.

`pathtrial --version` should print `pathtrial 1.6.0`.

## Scope

This release does not include WHOIS lookup, port scanning, multi-region remote
probes, a GUI or automatic network repair.

Key release binary SHA-256 values are recorded below and in each asset's
`.sha256` file.
