# PathTrial v1.5.0-rc.2

This is a **release candidate**, not a stable release. `v1.5.0-rc.1` and its assets are unchanged and do not include a Windows archive.

## Highlights

- Windows x86_64 archive `pathtrial-1.5.0-rc.2-x86_64-pc-windows-msvc.tar.gz` and a SHA-256 file, plus `install.ps1`.
- macOS Apple Silicon, macOS Intel, and Linux x86_64 archives are published the same way.
- Local allow file for MCP, offline `pathtrial report render`, local `pathtrial baseline`, and `scripts/peer.sh`.
- Cursor plugin package under `plugins/cursor/pathtrial/`. It is not listed on the public Cursor Marketplace.

## Install

Verify the `.sha256` file beside the archive before installing.

- macOS and Linux: `install.sh` from this Release, into `~/.local/bin` by default.
- Windows: `install.ps1` from this Release. It copies `pathtrial.exe` to `%LOCALAPPDATA%\PathTrial` and does not change PATH, firewall, DNS, or routes.

`pathtrial --version` should print `pathtrial 1.5.0-rc.2`.

## Limits

- Windows `--bind-interface` is an error and does not use another interface.
- Windows per-target routes, ICMP jitter, and Wi-Fi dBm are not established.
- Cursor Desktop install and the public Marketplace listing are not verified by this release.
- Probe tools stay default-deny. `mcp.json` arguments remain `["mcp"]`.

See [Windows](https://github.com/gaochenyang666-droid/PathTrial/blob/v1.5.0-rc.2/docs/windows.md) and [AI integration](https://github.com/gaochenyang666-droid/PathTrial/blob/v1.5.0-rc.2/docs/ai-integrations.md).
