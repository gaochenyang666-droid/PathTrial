PathTrial 1.4.0-rc.1

下载应用

基于可验证证据的网络诊断 CLI。选择对应平台，或使用安装脚本自动识别 macOS Apple Silicon、macOS Intel 和 Linux x86_64。

curl -fsSL https://github.com/gaochenyang666-droid/PathTrial/releases/download/v1.4.0-rc.1/install.sh | sh

直接下载

macOS Apple Silicon 适用于 M1、M2、M3、M4 下载 .tar.gz
macOS Intel 适用于 x86_64 Mac 下载 .tar.gz
Linux x86_64 适用于 Ubuntu 24.04 等 x86_64 发行版 下载 .tar.gz

所有压缩包均附带 SHA-256 校验文件，安装脚本会在安装前验证。
