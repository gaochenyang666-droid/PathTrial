通过官方安装脚本安装

推荐先下载并检查安装脚本，再执行它。脚本按平台下载匹配的压缩包，验证 SHA-256 后安装到 ~/.local/bin。

curl -fsSLo pathtrial-install.sh \
  https://github.com/gaochenyang666-droid/PathTrial/releases/download/v1.5.0-rc.1/install.sh
less pathtrial-install.sh
sh pathtrial-install.sh
export PATH="$HOME/.local/bin:$PATH"
pathtrial --version
pathtrial mcp --help

安全提示：不建议直接将远程脚本通过管道传入 Shell；请先阅读脚本内容。如选择手动安装，请先检查压缩包对应的 SHA-256 文件。

安装后检查

独立 CLI

在终端运行 pathtrial --version、pathtrial scan --help。试用网络诊断前确认目标是你有权检测的设备或服务。

MCP / AI 插件

运行 pathtrial mcp --help，然后根据 集成指南安装 Codex 或 Claude Code 的 Marketplace 插件。
