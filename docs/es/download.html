Instalar mediante el script oficial

Descarga y revisa el script antes de ejecutarlo. Selecciona el paquete adecuado y verifica su SHA-256 antes de instalarlo en ~/.local/bin.

curl -fsSLo pathtrial-install.sh \
  https://github.com/gaochenyang666-droid/PathTrial/releases/download/v1.5.0-rc.1/install.sh
less pathtrial-install.sh
sh pathtrial-install.sh
export PATH="$HOME/.local/bin:$PATH"
pathtrial --version
pathtrial mcp --help
Seguridad: evita ejecutar scripts remotos mediante una tubería directa a Shell. Revisa el script o verifica manualmente el SHA-256.
