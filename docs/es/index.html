El diagnóstico guiado v1.6 ya está disponible

Incluye path fingerprint y 14 escenarios. Los informes separan observaciones, causas posibles, cuestiones pendientes y siguientes comprobaciones.

pathtrial diagnose --scenario web example.com
pathtrial diagnose --scenario vps YOUR_VPS_IP --port 22
pathtrial diagnose --scenario latency example.com --rounds 10
pathtrial diagnose --scenario proxy --url https://example.com/ --proxy socks5://127.0.0.1:1080
pathtrial diagnose --scenario local
Versión estable v1.6.0: incluye diagnose, path fingerprint y 12 herramientas MCP. Hay paquetes verificados para macOS, Linux y Windows x86_64.

Utiliza el CLI sin una cuenta de IA

Ejecuta las pruebas en macOS o Linux sin servicios en la nube. PathTrial no modifica DNS, rutas, proxies ni cortafuegos automáticamente.

Los informes usan PASS, WARN, FAIL, SKIP e INCONCLUSIVE y citan identificadores reales de cada prueba.

Preguntas frecuentes

¿En qué se diferencia de ping o curl?

PathTrial mide varias capas, cita identificadores de pruebas reales y señala qué causas quedan sin demostrar.

¿Necesito Rust para instalarlo?

No. Hay paquetes para macOS ARM64, macOS Intel y Linux x86_64.

¿Comprueba equipos sin permiso?

Las pruebas MCP se bloquean de forma predeterminada. Autoriza cada destino y elimina datos sensibles antes de compartir informes.
