Install with the release script

Download and inspect the script before running it. It selects a compatible archive and checks its SHA-256 hash before installing to ~/.local/bin.

curl -fsSLo pathtrial-install.sh \
  https://github.com/gaochenyang666-droid/PathTrial/releases/download/v1.5.0-rc.1/install.sh
less pathtrial-install.sh
sh pathtrial-install.sh
export PATH="$HOME/.local/bin:$PATH"
pathtrial --version
pathtrial mcp --help
Security: do not pipe a remote installer directly into your shell. Review the script or manually verify the archive checksum.
