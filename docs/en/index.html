v1.5 guided diagnosis is available in the public release candidate

The diagnose command offers 11 named scenarios covering 10 common classes of connectivity problems. Reports distinguish observations, possible causes, unresolved questions and recommended next checks.

pathtrial diagnose --scenario web example.com
pathtrial diagnose --scenario vps YOUR_VPS_IP --port 22
pathtrial diagnose --scenario latency example.com --rounds 10
pathtrial diagnose --scenario proxy --url https://example.com/ --proxy socks5://127.0.0.1:1080
pathtrial diagnose --scenario local
Public prerelease: the v1.5.0-rc.1 binaries include guided diagnosis and 10 MCP tools. Three platform release builds and MCP smoke checks passed. Windows is not supported.

Use the CLI without an AI account

Run checks directly on macOS or Linux. No cloud account or background service is needed; PathTrial does not automatically change DNS, routes, proxies or firewall settings.

Reports use PASS, WARN, FAIL, SKIP and INCONCLUSIVE, and refer to measured probe IDs rather than invented causes.

Frequently asked questions

How is PathTrial different from ping or curl?

It records separate protocol measurements, traces findings to probe IDs, and states what evidence does not establish.

Do I need Rust to install?

No. Prebuilt packages are available for macOS ARM64, macOS Intel and Linux x86_64.

Does PathTrial test unauthorized devices?

MCP network probes are denied by default. Authorize individual targets before testing and remove sensitive details before sharing reports.
