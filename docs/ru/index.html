Для решения реальных сетевых проблем

Каждый этап подключения проверяется отдельно. Успешный ping ещё не подтверждает работу приложения.

Сайты и DNS

Отделяйте ошибки DNS, TCP-подключения, TLS и HTTP-ответа.

VPS и прокси

Проверяйте порты, SOCKS5 / HTTP CONNECT, UDP Echo, QUIC и HTTP/3 раздельно.

IPv4 и IPv6

Сравнивайте два стека при одинаковых целях, портах, числе попыток и тайм-аутах.

Диагностика v1.6 доступна в стабильном выпуске

Команда diagnose и path fingerprint поддерживают 14 сценариев. Отчёты разделяют наблюдения, возможные причины, неподтверждённые выводы и следующие проверки.

pathtrial diagnose --scenario web example.com
pathtrial diagnose --scenario vps YOUR_VPS_IP --port 22
pathtrial diagnose --scenario latency example.com --rounds 10
pathtrial diagnose --scenario proxy --url https://example.com/ --proxy socks5://127.0.0.1:1080
pathtrial diagnose --scenario local
Стабильный выпуск v1.6.0 содержит diagnose, path fingerprint и 12 инструментов MCP. Пакеты проверены для macOS, Linux и Windows x86_64.

CLI работает без аккаунта ИИ

Запускайте проверки на macOS или Linux без облачного сервиса. PathTrial не меняет DNS, маршруты, прокси и брандмауэр автоматически.

В отчётах используются PASS, WARN, FAIL, SKIP и INCONCLUSIVE; выводы ссылаются на реальные идентификаторы проб.

Интеграция с Codex и Claude Code

Локальные MCP-плагины версии 0.4.0 предоставляют двенадцать инструментов, включая диагностику и объяснение отчётов.

OpenAI Codex

Установите плагин через Marketplace и проверьте локальное MCP-подключение.

codex plugin marketplace add \
  gaochenyang666-droid/PathTrial
codex plugin add pathtrial@pathtrial

Claude Code

Установите плагин в Claude Code и откройте /mcp.

/plugin marketplace add gaochenyang666-droid/PathTrial
/plugin install pathtrial@pathtrial

Частые вопросы

Чем PathTrial отличается от ping или curl?

Утилита проверяет уровни сети отдельно, ссылается на реальные пробы и отмечает неподтверждённые причины.

Нужен ли Rust для установки?

Нет. Есть готовые пакеты для macOS ARM64, macOS Intel и Linux x86_64.

Проверяет ли программа чужие устройства?

Сетевые вызовы MCP по умолчанию запрещены. Требуется явное разрешение цели; перед отправкой отчётов удаляйте секреты.
