Версия v1.5.0-rc.1 включает CLI для диагностики сети и локальный MCP-сервер. Готовые пакеты доступны для macOS Apple Silicon, macOS Intel и Linux x86_64.

Это общедоступный кандидат на выпуск, пока не стабильная версия. Пакеты и их SHA-256 опубликованы на GitHub Releases. GitHub Releases.

Включает diagnose, десять MCP-инструментов и объяснение отчётов. Сборки и контрольные суммы для трёх платформ проверены. Предыдущая версия v1.4 доступна отдельно.

Установка через официальный скрипт

Сначала загрузите и проверьте скрипт. Он выбирает подходящий пакет, сверяет SHA-256 и устанавливает программу в ~/.local/bin.

curl -fsSLo pathtrial-install.sh \
  https://github.com/gaochenyang666-droid/PathTrial/releases/download/v1.5.0-rc.1/install.sh
less pathtrial-install.sh
sh pathtrial-install.sh
export PATH="$HOME/.local/bin:$PATH"
pathtrial --version
pathtrial mcp --help
Безопасность: не запускайте удалённый скрипт напрямую через конвейер Shell. Прочитайте код скрипта или проверьте SHA-256 архива вручную.

Проверка установки

Самостоятельный CLI

Запустите pathtrial --version и pathtrial scan --help. Проверяйте только разрешённые цели.

MCP / ИИ-плагины

Запустите pathtrial mcp --help, затем следуйте руководству по интеграции Codex или Claude Code. AI integration guide.
